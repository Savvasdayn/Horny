## Основа Git

### Зачем Git?

#### Почему не флешка?

1. Флешка - потенциальный разносчик вирусов
2. Ваши личные данные могут случайно попасть на чужой компьютер
3. Антивирус может удалить ваши файоы с флешки
4. Флешка может поряться или сломаться

#### Почему не Yandex или Google диск?

1. Облако Yandex или Google не контролирует версии файлов
2. Ваши данные к Yandex или Google могут случайно остаться на чужом компьютере

### Преимущества Git

1. Трудно потерять свои проекты
2. Легко отслеживать версии проектов
3. Легко делиться с другими людьми вашими проектами
4. Легко вести современную работу над одним проектом
5. Git - де-фактно стандарт в IT и интегрирован почти во все современные технологии IT (VS CODE)
6. В Git можно создавать веб-страницы как хостинге
7. Git-сервисы дают возможности автоматизировать сборки и тестирования приложений
8. Основные состояния Git-репозитория
9. Инициализация - git status - показывает текущее состояние репозитория
10. **Подготовка** - `git add .` - подготовка (добавление) изменений
11. **Фиксация** - `git commit -m 'Some message'`
12. **Синхронизация** - удаленной копией текущего репозитория - `git push` и `git pull`


### Что можно сохранять в Git?

1. любые тексовые файлы, объемом <= ~40mb.
2. Изображения, документы, mp3, PDF, короткие видео и т.п.
3. Все имена файлов и каталогов только по-английски без пробелов и спец.символов!

### Основные команды Git

Получить версию установленного Git:
```shell
git version
```
или
```shell
git --version
```
Получить справку
```shell
git help
```
**Сменить текстовый редактор по умолчанию**
На `Micro` (проще для новичков)
```shell
git config --global core.editor "micro"
```
На `Nano` (чуть сложнее для новичков)
```shell
git config --global core.editor "nano"
```
На `VS Code` (элементарен для новичков)
```shell
git config --global core.editor "code --wait"
```
**Представиться системе Git**
Сообщить свой никнейм
```shell
git config --global user.name "Fixic"
```
Сообщить свой эмэйл
```shell
git config --global user.email "my_email@mail.ru"
```

**Если вы на чужом компьютере, то вместо `--global` используйте `--local`**

#### Клонирование репозитория

``` shell
git clone http://gitflic.ru/project/nickname/mfua
```
открыть папку клонированного репозитория
```shell
cd folder_name
```
Получить статус текущего репозитория
```shell
git status
```
Получить состояние удаленного репозитория
```shell
git remote show origin
```
```shell
git branch
```
```shell
git branch --v
```
