## Bash

Bash - это консоль (CLI) и скриптовой Язык програмирования 

### Управление Терминалом (консоль)

Сдвинуть лог вверх 
`Ctrl+L` 

Очистить экран
`Clear` 

Получить историю 
```shell 
history
```

 Перелистывание ранее введеных команд 
 `Стрелка  вверх/Стрелка вниз`

 Выполнить последнюю (из списка History) команду
```shell
!!
```
Выполнить указаннуб команду из списка history 
```shell 
!45
```
где `45` порядковый номер команды из history

Остановить запущенный в консоле процесс по `Ctrl+C`

### Файловые операции

Получить структуру каталогов и файлов 
```shell
tree
```
получить абсолютный путь к текущему каталогу 
```shell
pwd
```
показать содержимое текущего каталога
```shell
ls
```
или подробно 
```shell
ll
```
или
```shell
ls -all
```
или показать содержимое указанной папки 
```shell
Is Dir_name
```
где `Dir_name` - это имя нужной папки

правила именованич калогой и фалов:
1. Только по-английски
1. Без пробелов  и спец. символов
1. Если имя файла или каталога состоит из несколько английских слов, то имя можно создать так: `firstOfall` или `first_of_all` 
1. В имени файлов лучше всегда указывать расширение `fileName.txt` 

выйти из текущей папки 
```shell
cd ..
```
Вернуться в предыдущую папку 
```shell
cd - 
```
Зайти в указанную папку 
```shell
cd TargetFolder
```

знаки:
`\` - обратный слэш - признак каталога
`/` - прямой слэщ - признак каталога 
`|` - вертикальный слэш - признак разделения команд

Windows
`\` - корневой каталог
Unix/Linux/Android/macOS/iOS/BSD:
`/` - корневой каталог

Выйтм из текущего каталога на 2 шага вверх
```shell
cd../..
```

#### Создание файлов и каталогов

Создание файлов
```shell
touch file_name.txt
```
редактировать файл
```shell
touch file_name.txt
```
`micro` - текстовый редактор командной строк
- сохранить по `Ctrl+S`и выйти из редактора по `Ctrl+Q`

Переименовать файл
```shell
mv old_name new_name
```
копирование файла 
```shell
cp name_file.txt NemFolder/
```
переместить файл 
```shell
mv file.txt TargetName
```
Удалить файл 
```shell
rm delFile.txt
```
Удалить папку 
```shell
rm -rf DelFolder
```
Создать несколько файлов 
```shell
touch {1..3}.txt
```
Создать несколько каталогов
```shell
mkdir folderName{1..4}
```
Удалить содержимое текущего каталога
```shell
rm -rf *
```
Создать структуру проекта:
```shell
project/
├── css/
├── js/
├── img/
│   └── ico/
├── fonts/
└── pages/
```
Создать такую структуру одной командой:
```shell
mkdir -p project/{css,js,img/ico,fonts,pages}
```

### Linux

Имя компьютера
```shell
hostname
```
Локалбный IP
```shell
hostname -i
```
сетевая информация 
```shell
ifconfig
```
или
```shell
ip -c  r
```
или
```shell
ip -c  a
```
Пинг 
```shell
ping ya.ru
```
или определенное кол-во раз
```shell
ping -c 4 ya.ru
```
получить ин-фу по домену
```shell
whois ozon.ru
```
Получить порты
```shell 
netstat -an
```
Получить маршруты
```shell
route
```
Выйти из сеанса пользователя
```shell
exit
```
Перезагрузить
```shell
reboot
```
Выключить
```shell
poweroff
```
Получить текущее время
```shell
date
```
Календарь
```shell
cal
```
или 
```shell
cal 2027
```
Получить общую ин-фу по система
```shell
inxi -F
```
